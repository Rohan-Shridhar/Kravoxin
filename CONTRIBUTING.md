# 🚀 Contributing to Kravoxin

Hey there! Thanks for taking the time to check out **Kravoxin**! 🎉 

Whether you're fixing a bug, suggesting a cool new feature, or improving documentation, all contributions are super welcome. Let’s build something awesome together! 💥

---

## 🚦 Phase 2 Policy (Important Note!)

📌 **Please Note:** 
We are currently focusing all our energy on polishing and delivering **`v2.0.0`**. 

* **Phase 2 issues** will be **assigned and solved ONLY AFTER the release of `v2.0.0`**.
* You can still open issues or ideas for Phase 2, but they’ll be resting in the chill zone 🧊 until `v2.0.0` goes live!

---

## 🛠️ How to Contribute

Got an itch to code or improve something for `v2.0.0`? Here's the recipe:

1. Fork this repository to your GitHub account.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/rohan-shridhar/Kravoxin.git
   cd Kravoxin
   ````
3. Create your branch
4. Commit your changes
5. Open a PR and make sure to mention the issue you worked on
