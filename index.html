What does Kravoxin do?

Kravoxin captures every text snippet, code block, and command you copy on web pages and indexes it in your browser's local storage. You can view chronological history, search snippets instantly, star critical items, and re-copy them to your clipboard with one click.

Does Kravoxin transmit any clipboard data to cloud servers?

Zero bytes. Kravoxin is strictly local-first. All clippings are stored inside chrome.storage.local within your browser sandbox. There are no remote API servers, no telemetry trackers, and no analytics beacons.

How do I install Kravoxin in Chrome, Brave, or Edge?

Clone or download the repository, navigate to chrome://extensions/ (or edge://extensions/), toggle Developer mode on in the upper-right corner, and click Load unpacked. Select the Kravoxin repository folder, and the extension is instantly active.

What happens when I clear history?

Clicking Clear All cleans all unstarred snippets from local storage, keeping your favorite pinned snippets intact. You can also delete individual snippets at any time with the trash can icon.

Why is Manifest V3 compliance important?

Manifest V3 ensures that the extension uses event-driven service workers that sleep when not in use. This prevents battery drain, reduces background memory usage to near zero, and complies with modern Chrome security standards.

Can I use Kravoxin with keyboard shortcuts?

Yes. You can assign a custom keyboard shortcut to open the Kravoxin popup by visiting chrome://extensions/shortcuts in your browser.

Is Kravoxin completely free and open source?

Yes. Kravoxin is released under the MIT Open Source License. You are free to inspect the source code, modify it, or contribute improvements on GitHub.
