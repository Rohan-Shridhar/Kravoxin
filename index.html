UNDER THE HOOD

Works seamlessly with your tech stack.

Kravoxin follows strict Manifest V3 architecture guidelines. It leverages asynchronous storage promises, normalized data shapes, and passive event interception to ensure zero browser overhead.

  • Event-Driven Background Service Worker Runs only when copy events occur, terminating automatically to preserve CPU cycles and battery life.
  • Normalized Schema with Precise Timestamps Items are tracked with yyyymmddhhmmss formats, duplicate resilience, and explicit favorite flags.
  • Minimalist Permission Footprint Requires strictly storage and clipboardWrite. Zero access to browsing history or personal tabs.

// Kravoxin Storage Helper Engine
async function addHistoryItem(text, timestamp = formatCopyTimestamp()) {
  const history = await getHistory();
  
  // Newest items prepend to the front
  history.unshift({
    text,
    favorite: false,
    timestamp
  });

  await saveHistory(history);
}

// Protected bulk clear preserving starred items
async function clearAllHistory() {
  const history = await getHistory();
  const favoritesOnly = history.filter((item) => item.favorite);
  await saveHistory(favoritesOnly);
}
// Manifest V3 Background Service Worker
importScripts('storage.js');

chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type === 'TEXT_COPIED' && message.payload) {
    addHistoryItem(message.payload)
      .then(() => sendResponse({ success: true }))
      .catch((err) => sendResponse({ success: false, error: err }));
    return true; // Keep channel open for async response
  }
});
// Passive DOM Clipboard Observer
document.addEventListener('copy', () => {
  // Read selection from active document
  const selectedText = window.getSelection()?.toString()?.trim();
  
  if (selectedText && selectedText.length > 0) {
    chrome.runtime.sendMessage({
      type: 'TEXT_COPIED',
      payload: selectedText
    });
  }
});
QUICKSTART GUIDE

Get up and running in under 60 seconds.

No complex setup or account registration required. Load Kravoxin directly into Chrome as an unpacked developer extension.

01

Clone or Download

Clone the repository from GitHub or download the source code archive to your local drive.

02

Open Extensions

Navigate to chrome://extensions/ in your Google Chrome or Chromium browser.

03

Developer Mode

Toggle on the Developer mode switch in the upper right-hand corner of the page.

04

Load Unpacked

Click the Load unpacked button and select the downloaded Kravoxin root folder.
